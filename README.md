# Gerenciador de Tarefas Simples

Este projeto foi desenvolvido como parte de uma atividade prática sobre Git e GitHub. O objetivo é demonstrar o uso de versionamento de código, gerenciamento de branches, criação de issues e pull requests.

## 🚀 Funcionalidades
- **Adicionar Tarefas**: Permite inserir novas tarefas na lista.
- **Remover Tarefas**: Cada tarefa possui um botão para ser excluída individualmente.
- **Interface Moderna**: Design limpo e responsivo utilizando CSS moderno.

## 🛠️ Tecnologias Utilizadas
- HTML5
- CSS3 (Flexbox, Gradients)
- JavaScript (Vanilla)

## 📋 Atividade Prática Realizada
1. **Repositório**: Criado no GitHub para armazenamento.
2. **Commits**: Realizados de forma organizada seguindo padrões básicos.
3. **Branches**: 
   - `feature/delete-task`: Implementação da remoção de tarefas.
   - `feature/styling-update`: Melhorias visuais e de UX.
4. **Issue**: Criada a issue #1 para documentar a necessidade de melhorias visuais.
5. **Pull Request**: Realizado o merge das branches para a `main` via PR.
